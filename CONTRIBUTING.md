# Contributing

Thank you for your interest in contributing to the Customer 360 Analytics Platform.

## Getting Started

If you would like to contribute, please follow these steps:

1. Fork the repository.
2. Create a new feature branch.
3. Make your changes.
4. Commit your changes with clear commit messages.
5. Push your branch.
6. Open a Pull Request.

## Coding Guidelines

### Python

- Follow PEP 8 coding standards.
- Write modular and reusable functions.
- Include comments where necessary.

### SQL

- Use meaningful table and column names.
- Keep queries readable and well formatted.
- Document complex transformations.

### Documentation

- Update the README if new functionality is added.
- Keep diagrams and screenshots up to date.

## Reporting Issues

If you find a bug or have a feature request, please create an Issue describing:

- Problem
- Expected behaviour
- Steps to reproduce
- Screenshots (if applicable)

## Thank You

Thank you for helping improve this project!
